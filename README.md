# AI Intelligence OS

AI-native intelligence and investigation platform.

## Product goals

- Current, source-backed intelligence
- Universal investigations across people, businesses, domains, social, images, and digital assets
- Evidence-first provenance and confidence scoring
- Entity-resolution graph and investigation workbench
- Specialized AI investigation agents and grounded case analysis
- Continuous monitoring and change detection
- Original product branding and UI

## Development principles

1. Never fabricate intelligence or evidence.
2. Keep source/provider integrations replaceable and health-monitored.
3. Record source, timestamp, provenance, confidence, and contradictions for findings.
4. Prefer current provider documentation and live data over stale assumptions.
5. Build the product as a production system, not a static demo.

## Initial architecture

The repository will be organized as a production monorepo with a web application, API/services, shared domain contracts, provider adapters, database migrations, tests, and deployment configuration.
