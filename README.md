# AI Intelligence OS

AI-native intelligence and investigation platform.

## CashFlowOS pilot

CashFlowOS is the first focused business-product MVP in this repository: it turns a B2B SME's outstanding-invoice CSV into a prioritized collection plan.

**Workflow:** Upload CSV → Analyze receivables → Prioritize collection → Draft follow-up.

Target pilot customers: distributors, wholesalers, and small manufacturers.

Required CSV fields: `customer_name, invoice_id, due_date, invoice_amount, paid_amount`.

The current MVP is a sales/demo prototype. It does not replace accounting software, provide multi-user authentication, or persist customer data in a server database yet.

## Original AI Intelligence OS goals

- Current, source-backed intelligence
- Universal investigations across people, businesses, domains, social, images, and digital assets
- Evidence-first provenance and confidence scoring
- Entity-resolution graph and investigation workbench
- Specialized AI investigation agents and grounded case analysis
- Continuous monitoring and change detection
